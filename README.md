# Watchlist

Application 100% gratuite et sans pub pour suivre sa watchlist, ajouter des films et choisir le film du jour. Alimentée par l'API TMDB.

## Télécharger l'application (APK)

Pour installer l'application sur votre téléphone Android :

[Télécharger la version pour Android (APK)](https://github.com/IbanMarlats/Watchlist/releases)

### Comment l'installer sur votre téléphone :
1. Téléchargez le fichier APK depuis la page des Releases ci-dessus.
2. Ouvrez le fichier sur votre téléphone.
3. Si Android vous demande confirmation, autorisez l'installation depuis cette source dans vos paramètres.
4. Appuyez sur Installer, puis lancez l'application.

---

## Ce que permet l'application

- Garder une liste des films que vous voulez voir et de ceux que vous avez déjà vus.
- Chercher des films avec leurs affiches, résumés, durées et acteurs via la base TMDB.
- Trouver quoi regarder quand vous hésitez grâce à la sélection de films.
- Tout reste sur votre téléphone : aucune création de compte, pas de tracking et pas de pub.
- Possibilité d'utiliser votre propre clé TMDB dans les paramètres.
